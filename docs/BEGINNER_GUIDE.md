# Inicio para principiantes

La portada ahora es el punto de partida. El analizador completo sigue en `lab.html`.

1. Pulsa **Empieza aquí** para abrir la primera lección.
2. Lee el concepto, observa el ejemplo y realiza la práctica propuesta.
3. Usa **Siguiente lección** para avanzar o **Elegir otra lección** para consultar el índice completo.
4. En **Practicar**, marca las etapas que puedas explicar. El inicio ofrece continuar con la primera etapa sin marcar.

El progreso existente se conserva en el mismo almacenamiento local. No es una certificación ni se sincroniza entre dispositivos. El taller permite exportarlo e importarlo.

La navegación principal se reduce a Inicio, Aprender, Ver ejemplos y Practicar. Analizador, ayuda y video siguen en Más opciones. Los enlaces antiguos a las secciones del analizador se redirigen al laboratorio.

No se han retirado lecciones, ejemplos, diagramas, videos ni funciones del analizador. La lectura individual muestra una lección y volver al índice permite acceder a las demás y a las fuentes.
